Privacy Policy

Last updated: 4 November 2026

Channel Tools (OAuth app name: youtube-mcp) is a personal tool used only by its owner, Martin Šebek, to manage his own YouTube channels.

What data the app accesses

  • YouTube Data API: the owner's channel details, videos, playlists and comments, to read and edit them.
  • YouTube Analytics API (read-only): views, watch time, retention and traffic sources of the owner's channels.

How the data is used and stored

  • Data is processed only on the owner's own computer to display statistics and apply changes the owner requests.
  • OAuth tokens are stored locally on that computer and are never shared.
  • No data is sold, shared with third parties, or used for advertising.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. YouTube's terms apply: YouTube Terms of Service, Google Privacy Policy.
