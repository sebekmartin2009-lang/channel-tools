Channel Tools

Channel Tools (OAuth app name: youtube-mcp) is a private, single-user tool that lets its owner, Martin Šebek, manage his own YouTube channels from his own computer: reading channel and video statistics, editing titles and descriptions, and preparing uploads.

It is not offered to the public and has no other users.

Channel Tools uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API).
